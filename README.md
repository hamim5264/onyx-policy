# Onyx App Policies & Legal Documents

This repository hosts the official legal documents, policy pages, and user instructions for the **Onyx** expense tracker application.

These pages are hosted publicly using GitHub Pages.

---

## Hosted Legal Pages

*   **Privacy Policy**
    *   **Description:** Explains how Onyx collects, processes, and protects user data, including disclosures regarding optional local transactional SMS scanning, AI budgeting assistants, and third-party social logins (Google & Meta).
    *   **Live Link:** [https://hamim5264.github.io/onyx-policy/](https://hamim5264.github.io/onyx-policy/)

*   **Terms of Service**
    *   **Description:** Outlines the terms and rules of using the Onyx application, including account registrations, SMS permission, and disclaimers regarding the AI financial assistant.
    *   **Live Link:** [https://hamim5264.github.io/onyx-policy/terms.html](https://hamim5264.github.io/onyx-policy/terms.html)

*   **User Data Deletion Instructions**
    *   **Description:** Provides step-by-step instructions on how users can request the deletion of their accounts and associated data either in-app or via support email.
    *   **Live Link:** [https://hamim5264.github.io/onyx-policy/data-deletion.html](https://hamim5264.github.io/onyx-policy/data-deletion.html)
