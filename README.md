## Running the Project Locally

Because this project is a static website (HTML5, modern CSS3, vanilla JavaScript), you do not need complex build steps. You can preview it using any of the following methods:

### Method 1: VS Code Live Server (Easiest)
1. Open this repository in VS Code.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click on `index.html` and choose **"Open with Live Server"**.
4. The site will automatically open at `http://127.0.0.1:5500/`.

### Method 2: Python HTTP Server (Built-in)
If you have Python installed, open your terminal in this repository folder and run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

### Method 3: Node.js `serve` or `npx http-server`
```bash
npx serve .
# or
npx http-server . -p 8000
```
Then open the local URL shown in your terminal.

### Method 4: Direct Browser Open
Simply double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox.
